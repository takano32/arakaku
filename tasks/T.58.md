# T.58 「データが更新されました。」が頻繁に出る原因を直す

- 状態: 完了
- 期間: 2026-10-25

2026-10-25 にユーザーが依頼:「データが更新されました。が頻繁に出るので原因を調査してください」。

- 原因: GitHub Pages の ETag は「更新時刻-サイズ」（例 `"6add8ef6-89c5"`）。Pages のワークフローは push のたびに `make build` で `docs/data/*.json` を作り直すため、データが変わらない push（TASKS.md だけなど）でも全 JSON の ETag と Last-Modified が変わり、`sw.js` が更新とみなして通知していた。
- [x] T.58.1 `sw.js` で再取得した本文をキャッシュの本文と比べ、違うときだけ通知する。ページへ返した Response の本文は読まれているので、比べる本文はキャッシュから取り直す（c5ce85c、2026-10-25）。ローカルで「更新時刻だけ変更 → 通知なし・キャッシュの検証子は更新」「本文を変更 → 通知あり」を確認
